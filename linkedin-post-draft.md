**How to install**

1. Clone the repository:
   `git clone https://github.com/shahutopia-dev/social-media-skills.git`
2. Drop the folder into your Claude or Codex project.
3. Start with `voice-builder`.

Every skill reads your voice profile after you build it, which helps the output sound like you.
